Controls & project notes

Controls

Keyboard and mouse. Open the double-helix icon to enter the evolution lab. P pauses or resumes; R restarts. Select an organism to inspect it, switch environments and compare the control curve. Some lab hover explanations are currently in Chinese.

Project notes

An experimental sandbox about inheritance, variation and selection. The evolution lab is an abstract game model, with game parameters and a matching control population.
